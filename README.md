# New Project

פרויקט Python לדוגמה הכולל דשבורד אינטרקטיבי ב-Dash וסקריפט הדגמה פשוט.

## תוכן הפרויקט

| קובץ | תיאור |
|------|--------|
| `test.py` | דשבורד אינטרקטיבי בעברית — תפריט בחירה וגרף עמודות לפי קטגוריה |
| `test_damo.py` | סקריפט הדגמה שמדפיס הודעת בוקר |

## דרישות

- Python 3.8 ומעלה
- חבילות: `dash`, `plotly`, `pandas`

## התקנה

```bash
pip install dash plotly pandas
```

## הרצה

### דשבורד אינטרקטיבי

```bash
python test.py
```

לאחר ההרצה, פתח בדפדפן את הכתובת שמוצגת בטרמינל (בדרך כלל `http://127.0.0.1:8050`).

בדשבורד תוכל לבחור קטגוריה מהתפריט הנפתח ולראות גרף עמודות מעודכן בהתאם.

### סקריפט הדגמה

```bash
python test_damo.py
```

## מבנה הנתונים בדשבורד

`test.py` משתמש בטבלת דוגמה עם עמודות `קטגוריה` ו-`ערך`, ומציג גרף עמודות לפי הבחירה בתפריט.
